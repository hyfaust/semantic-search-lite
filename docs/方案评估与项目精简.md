## 二、GUI vs CLI 方案对比

### 方案 A：简化 GUI（Tauri 精简版）

```
工程量评估：
├── 需剥离的代码：~8,000 行（commands, tray, window, icon, ui_controller...）
├── 需新增的代码：~2,000 行（简化前端 + 简化 Tauri 命令）
├── 需修改的代码：~3,000 行（去掉 Windows API 依赖）
├── 总工程量：~13,000 行
└── 预估工期：3-4 周（一人）

构建依赖：
├── Rust 工具链
├── Node.js + bun（前端构建）
├── WebView2 运行时（Windows 自带）
├── tauri-cli（构建工具）
└── Vue 3 + TypeScript + Vite（前端）

产物大小：
├── Debug 构建：~150 MB（含 WebView2）
├── Release 构建：~30-50 MB
└── 运行时内存：500-1000 MB
```

### 方案 B：CLI 工具 ⭐ 推荐

```
工程量评估：
├── 需剥离的代码：~10,000 行（GUI 相关全部剥离）
├── 需新增的代码：~800-1,200 行（clap 参数解析 + 终端交互）
├── 需修改的代码：~1,500 行（简化 ProgramManager 初始化）
├── 总工程量：~12,500 行（但新增代码更少、更简单）
└── 预估工期：1.5-2 周（一人）

构建依赖：
├── Rust 工具链（仅此一项）
└── 无前端构建链

产物大小：
├── Debug 构建：~50-80 MB
├── Release 构建：~15-25 MB
└── 运行时内存：200-400 MB（主要是 ONNX 模型）
```

### 对比总结

| 维度 | GUI (Tauri) | CLI |
|------|-------------|-----|
| **工程难度** | ⭐⭐⭐⭐ 高 | ⭐⭐ 低 |
| **需新增代码** | ~2,000 行（含前端） | ~1,000 行（纯 Rust） |
| **构建依赖** | Rust + Node.js + bun | 仅 Rust |
| **Release 产物** | 30-50 MB | 15-25 MB |
| **运行时内存** | 500-1000 MB | 200-400 MB |
| **启动时间** | 3-5 秒 | <1 秒 |
| **调试复杂度** | 高（前端+后端+WebView） | 低（纯 Rust） |
| **交互体验** | 好（图形化） | 够用（终端表格/彩色输出） |
| **开发迭代** | 慢（需同时编译前后端） | 快（cargo run 一步到位） |

### 推荐理由

**CLI 方案更适合当前阶段**，原因：

1. **核心价值在算法，不在 UI**：语义检索的价值在于 embedding 质量和排序算法，CLI 已足够验证
2. **依赖链最简**：只需 Rust 工具链 + ONNX 模型文件，无 Node.js/bun/WebView2
3. **迭代最快**：改代码 → `cargo run` → 看结果，3 秒完成一次迭代
4. **后续可扩展**：核心逻辑抽为 library crate，GUI/Web/CLI 都可以作为前端调用
5. **跨平台潜力**：CLI 天然跨平台，不依赖 Windows API

│   ├── cli.rs                    # CLI 命令定义

## 四、开发环境配置要求

### 必需环境

| 工具 | 版本要求 | 用途 |
|------|---------|------|
| **Rust 工具链** | 1.80+ (MSRV) | 编译 Rust 代码 |
| **cargo** | 随 Rust 安装 | 包管理和构建 |
| **ONNX Runtime** | 自动下载（ort crate） | AI 模型推理 |
| **EmbeddingGemma 模型** | 300m onnx 版 | 语义向量生成 |

### 可选环境

| 工具 | 版本 | 用途 |
|------|------|------|
| Git | 2.40+ | 版本控制 |
| VS Code + rust-analyzer | 最新 | IDE 开发体验 |
| Python 3.10+ | 最新 | 对比测试 embedding 结果 |

### 不再需要的环境（GUI 方案才需要）

- ❌ Node.js / bun
- ❌ tauri-cli
- ❌ WebView2 SDK
- ❌ TypeScript / Vue
- ❌ Everything SDK

详细配置步骤见 `开发环境配置指南.md`。
